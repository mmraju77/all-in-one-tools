# Phase 1 Automation Workflow: Ideation to Audio & Visual Prompts

This document outlines the core backend automation workflow for Tube Master AI's MVP. Since the platform is built on a no-code stack (Bubble.io), complex API orchestration should be handled via **Bubble Backend Workflows**, **Make.com**, or **n8n**.

Below is the exact step-by-step logic, API payloads, and prompt engineering required to chain the user's input into a fully realized YouTube script, voiceover, and image asset generation.

---

## The Workflow Orchestrator (The "Main Loop")

**Trigger:** User clicks "Generate Video" in the Bubble frontend.
**Data Passed to Backend:** 
- `User_ID`
- `Workspace_ID`
- `Niche` (e.g., "Stoicism")
- `Topic` (e.g., "How to stop caring what people think")
- `Video Type` (e.g., "YouTube Shorts")

### Step 1: Initialize Job & Deduct Tokens (Bubble Backend)
1.  **Action:** Create a new `Content_Job` record in the database with status `Pending`.
2.  **Action:** Check `User`'s `token_balance`. If `< 1`, trigger "Insufficient Tokens" error to frontend.
3.  **Action:** Deduct `1` token from the user and log it in `API_Usage_Log`.

### Step 2: The Script Vault & hook Generation (OpenAI GPT-4o API)
We send the topic to OpenAI to generate the viral hooks, the main script, and the Midjourney/Fal.ai visual prompts.

*   **Endpoint:** `POST https://api.openai.com/v1/chat/completions`
*   **Payload structure:**

```json
{
  "model": "gpt-4o",
  "response_format": { "type": "json_object" },
  "messages": [
    {
      "role": "system",
      "content": "You are a master YouTube strategist and scriptwriter specializing in high-RPM Tier 1 niches. Output ONLY JSON. Generate a script for a {Video Type}. Include 3 viral A/B hooks targeting curiosity and emotion. For the main body, break it into 4-6 scenes. For each scene, include the exact narration text, and a highly detailed bracketed visual prompt for an AI image generator (Midjourney/Stable Diffusion) to match the narration. Use high contrast, ultra-realistic aesthetic."
    },
    {
      "role": "user",
      "content": "Niche: {Niche}. Topic: {Topic}."
    }
  ]
}
```

*   **Expected JSON Output mapped back to Bubble DB:**
    *   `seo_title`: Save to `Content_Job`
    *   `hooks`: Save to `Content_Job`
    *   `scenes`: List of objects containing `narration` and `visual_prompt`.

### Step 3: Scene Iteration (Make.com Router or Bubble Recursive Workflow)
Now that we have the scenes, we must process the audio and visuals **in parallel**.

#### Parallel Branch A: Hyper-Realistic Voiceover (ElevenLabs API)
Concatenate the chosen Hook + all `narration` text from the scenes. Send to ElevenLabs.

*   **Endpoint:** `POST https://api.elevenlabs.io/v1/text-to-speech/{Voice_ID}`
*   **Payload structure:**

```json
{
  "text": "{Concatenated_Narration}",
  "model_id": "eleven_multilingual_v2",
  "voice_settings": {
    "stability": 0.5,
    "similarity_boost": 0.75,
    "style": 0.2,
    "use_speaker_boost": true
  }
}
```

*   **Action:** ElevenLabs returns an `.mp3` audio stream. 
*   **Action:** Upload this `.mp3` to an AWS S3 bucket or Bubble's native storage. Save the resulting URL to `Content_Job.audio_url`.

#### Parallel Branch B: Visual Asset Generation (fal.ai / Stable Diffusion XL API)
For *each* scene generated by OpenAI, fire an API call to fal.ai using the `visual_prompt`. Remember to inject the `BrandKit.aesthetic_prompt_modifier` (e.g., "dark cinematic lighting, royal blue accents, 8k").

*   **Endpoint:** `POST https://fal.run/fal-ai/fast-sdxl`
*   **Payload structure:**

```json
{
  "prompt": "{Scene.visual_prompt}, {BrandKit.aesthetic_prompt_modifier}, --ar 16:9",
  "negative_prompt": "text, watermark, ugly, deformed, noisy, blurry",
  "num_inference_steps": 30,
  "guidance_scale": 7.5
}
```

*   **Action:** fal.ai returns a high-res image URL.
*   **Action:** Save these URLs sequentially into `Content_Job.visual_urls` (List of Texts).

### Step 4: Final Assembly & Notification (Creatomate API - Optional for Phase 1 MVP)
If you are moving to full video assembly (stitching the images and audio):

*   **Endpoint:** `POST https://api.creatomate.com/v1/renders`
*   **Payload:** Pass the `audio_url` and the array of `visual_urls`. Creatomate's timeline JSON allows you to auto-sync the images across the duration of the audio, and automatically generate kinetic typography.

### Step 5: Complete & Update Frontend
1.  **Action:** Update `Content_Job` status to `Complete`.
2.  **Action:** Trigger a UI update in Bubble (or send a webhook/email to the user) notifying them that their assets are generated.

## Next Steps for You

1.  **Create your API Keys:** Register for OpenAI, ElevenLabs, and fal.ai developer accounts.
2.  **Setup the Database:** Go to Bubble.io -> Data section, and recreate the tables defined in the `Platform_Architecture.md`.
3.  **Build the Backend Workflow API:** In Bubble, go to Backend Workflows and create a new API endpoint called `initiate_video_job`. This will be the trigger for Step 1.
